First release of MPC MIDI Converter: turns MIDI files into MPC patterns right on the MPC, with no computer.

## What's in it
- File browser for the MPC's drives (SD card, internal drive, USB): tap to highlight, tap again to open a folder or convert a file
- **Convert File**, and **Convert Folder** for a whole pack, including folders inside it (4 levels deep), keeping the pack's folder structure
- Patterns are saved in a **MIDI Converts** folder at the top of the drive the MIDI files are on; the status line says where
- The file's tempo goes in the pattern name, for example `Groove 01 (92 BPM).mpcpattern`
- **Split Tracks**: one pattern per instrument, named after the MIDI track
- **Drum Map**: General MIDI drums onto MPC pads (A01 kick, A02 snare, A03 hat...)
- **Quantize**: Off, 1/8, 1/16, 1/32
- **List**: Large (5 big rows) or Compact (8 rows), with a touch scroll bar
- **How To** page with the steps on screen
- Reads `.mid` and `.midi`, single-track and multi-track files, and keeps per-note pressure
- Listed with the instruments; Electric Violet design with large, readable text

## Safety
- Damaged or hostile MIDI files are refused instead of crashing MPC (tested with 300 corrupted files and crafted ones)
- Never reads or writes through links, never writes outside the drives, and caps memory use
