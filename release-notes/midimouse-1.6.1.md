# MIDIMouse 1.6.1

## Changed
- Right-click now defaults to the Grid tool-cycle (was Erase), since cycling to the eraser tool is handier
  than the Erase dialog.
- The tool-cycle now includes zoom: pencil -> eraser -> select -> zoom -> back (tool4 = 83,758).

## Notes
