# MIDIMouse 1.5.0

## Changed
- Renamed from MouseMIDI to MIDIMouse. The addin now installs to /data/mpc-addins/midimouse. No behaviour
  change from 1.4.1 - same mouse control (value wheel with acceleration, latch Shift, Erase, Stop/Play on the
  side buttons, mouse hot-plug, live config). Upgrading replaces the old MouseMIDI install.
